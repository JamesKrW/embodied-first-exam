## Task
Make and serve a capsule coffee (Franka, operational-space control). EmbodiedSWE's `puzzle.coffee.franka.osc` task (robobench at commit `67f44e8a2ca5`), privileged mode, with a program as the
deliverable: `solution/solve.py` exposing `solve(env)`.

## Difficulty
Long-horizon appliance use with a fixed order of operations: load a capsule into the machine's bay, slide the cover shut, stage a cup under the spout, press the button, wait for the fill and carry the full cup upright to the tray, all with one parallel gripper under torque control (OSC).

## Reference solution
None in the repository (`oracle = "none"`). No scripted reference has been written for this scene yet.

## Verification
`tests/grade.py` with EmbodiedSWE's grader for this scene, `tests/grader/coffee_service.py`, on the frozen instance (seed 0); the procedure (candidates, sandbox, 30-minute limit, selection, video) is the benchmark's, tasks/embodiedswe/README.md "Grading".
